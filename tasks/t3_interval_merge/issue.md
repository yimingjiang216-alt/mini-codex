# 区间 [1,3] 和 [3,5] 相邻却没有被合并

```python
>>> from intervals import merge
>>> merge([(1, 3), (3, 5)])
[(1, 3), (3, 5)]      # 期望 [(1, 5)]
```

首尾相接（前一个区间的终点等于后一个区间的起点）的区间应当合并成一个，
但当前实现用了严格小于比较，把这种情况漏掉了。

## 需要的行为

1. 首尾相接的区间要合并。
2. 完全被包含的区间要合并掉。
3. 输入未排序时也要正确合并，输出按起点升序。
4. 重复区间只保留一份。

## 验收

`repo/tests/test_issue.py` 覆盖上述行为，修复后应全部通过，
且 `test_existing.py` 不能被破坏。
