# 首尾相接的时间区间没有被合并

```python
>>> from slotkit import merge_busy
>>> merge_busy([(540, 600), (600, 660)])
[(540, 600), (600, 660)]      # 期望 [(540, 660)]
```

`(540, 600)` 是 9:00-10:00，`(600, 660)` 是 10:00-11:00，中间没有空隙，
应当合并成一个 `(540, 660)`。但当前实现把「相接」判成了「不相接」。

这个错误会往下游扩散。相接的区间没有被合并成一块，后续所有依赖
`merge_busy` 的功能都会算错：

```python
>>> from slotkit import merge_busy, largest_gap, fit_slot, summarize
>>> merge_busy([(540, 600), (600, 660), (660, 720)])
[(540, 600), (600, 660), (660, 720)]    # 期望 [(540, 720)]

>>> largest_gap([(540, 600), (600, 660)], 540, 1080)
420        # 看起来对，但 busy_count / 空闲窗口数都按 2 段算

>>> summarize([(540, 600), (600, 660)], 540, 1080)["busy_count"]
2          # 期望 1（本来是连成一片的占用）

>>> fit_slot([(540, 600), (600, 660)], 60, work_start=540, work_end=1080)
10:00-11:00    # 期望 11:00-12:00：相接处会冒出一个 0 分钟的假窗口
```

## 需要的行为

1. 首尾相接（前一个的 `end` 等于后一个的 `start`）的区间要合并成一个。
2. 已经重叠的区间仍然要合并（现有行为不能退化）。
3. 真正有空隙的区间必须保持分开。
4. `merge_busy` 的结果不能出现长度 0 的区间。
