# 引号内的逗号被错误地当成了分隔符

`csvlite.parse()` 现在直接按分隔符 split，所以下面这种带引号的字段会被切碎：

```python
>>> from csvlite import parse
>>> parse('a,"b,c",d')
[['a', '"b', 'c"', 'd']]        # 期望 [['a', 'b,c', 'd']]
```

## 需要的行为

1. 被双引号包裹的字段中，分隔符属于内容，不参与切分。
2. 引号内用两个连续双引号 `""` 表示一个字面双引号字符。
3. 完全不带引号的普通 CSV 必须保持原有行为不变。

## 验收

仓库里 `tests/test_issue.py` 中有针对上述行为的测试。修复后应全部通过，
同时 `test_existing.py` 里的原有测试不能被破坏。
